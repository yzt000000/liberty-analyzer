Liberty 库分析器

解析标准单元库 / IO 库 / 存储器的 .lib 文件，提取库级属性、单元属性、引脚与时序弧信息，并将查找表（LUT）以热力图 / 3D 曲面 / 数据表形式可视化。

1

加载库

下载内置开源库（Nangate45 / ASAP7 / SkyWater 130nm），或上传本地 .lib 文件，或输入 URL 直接抓取。

2

分析属性

库级单位 / 工作条件 / LUT 模板；每个 cell 的面积、漏电、引脚、功能表达式、时序弧、状态表。

3

图表化 LUT

delay / transition / power 查找表渲染为热力图、3D 曲面与原始数据矩阵，支持 CSV 导出。

下载开源 Liberty 库

以下库文件托管于 GitHub（OpenROAD-flow-scripts），按工艺/节点分组。下载时按 原始地址 → ghproxy 镜像 → GitHub API 顺序自动重试（国内网络通常走镜像成功）。标注 gz 的库为 .lib.gz 压缩格式，下载后自动解压（需 Chrome 80+ / Firefox 65+ / Safari 16.4+）。同组内的多 corner / 多 VT 库可用「对比」标签页直接对比：

自定义 URL

提示：GitHub raw 地址（raw.githubusercontent.com）支持跨域且会自动尝试镜像；其它站点若不允许跨域将无法抓取，请先下载到本地再用「上传 .lib」加载。大文件解析在后台线程进行，页面不会卡顿，可随时取消。

下载的库保存在哪里？

下载/上传的库只保存在当前网页的内存中（刷新页面即失效），不会写入磁盘——浏览器网页没有写本地文件的权限。应用的 libs/ 文件夹只包含内置的 3 个开源库。如需落盘：加载后点右上角「保存 .lib」按钮，浏览器会把它存到默认下载目录。
